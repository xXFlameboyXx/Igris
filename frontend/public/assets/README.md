# IGRIS Assets Directory

Place your custom IGRIS logo PNG at:
`igris-logo.png` (path: `frontend/public/assets/igris-logo.png`)

When this file is present, the IGRIS web application will automatically load and display it in the header and branding areas.
If this file is absent, IGRIS gracefully falls back to the built-in stylized "IGRIS" typographic badge.
